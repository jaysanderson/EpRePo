## 6. The single change that would move the score most

**Make the gate look up figures before it withholds them, and make the named-cohort guard apply to the question.** D3-01 and D3-02 are the two faces of the same mechanism: the audit only sees the paragraphs the platform happened to cite, so a correct figure from a retrieved-but-uncited paper is "unverifiable" and withheld (C1, R1, TD1, E2 - four of the six cross-paper or cohort questions I most need), while a wrong-cohort figure that happens to sit in a cited paragraph passes with a clean badge (C4). Concretely: (1) before removing a sentence, search every retrieved resource's full text and DA fields for the figure with normalised numbers, and if found, attach that resource's marker; (2) when the question names a cohort, drug or study, restrict figure sentences to the pinned paper(s) that match it, or require the sentence to name the other study; (3) run the same audit on briefing sections and key takeaways (D3-03). Platform: pin named studies with `resource_filters` and `rag_strategies: full_resource` so the audit index holds the whole paper, generate with `answer_json_schema` carrying `{figure, outcome, population, study, paragraph_id}` per statement, and bind markers from the platform's `citations` paragraph ids instead of the model's brackets. The document chat already proves the figures are in reach - it answered C4's question correctly on the same paper. This takes me from 7 to about 8.5.

Next three:
1. **Latency** (D3-05): release the first verified sentence immediately, cap the retry chain, run the per-entity retrievals in parallel; target under 6 s to the first visible sentence and refusals no slower than answers.
2. **Names** (D3-04, D3-11): full-name, initial and apostrophe-less author lookups; "X's papers" as author scope; never an answer built from declarations.
3. **The addenda** (D3-08, D3-13, D3-09): second-hand only for Introduction/Discussion, denominators only for proportions with an n in the same sentence, markers only where the paragraph carries the claim - so the notes under an answer are as trustworthy as the answer.
